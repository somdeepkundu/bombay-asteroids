## Quick Start

**Play online:** https://somdeepkundu.github.io/bombay-asteroids/

**Run locally:**
```bash
git clone https://github.com/somdeepkundu/bombay-asteroids.git
cd bombay-asteroids
python -m http.server 8000
# Open http://localhost:8000
```

---

## Controls

| Action | Key |
|---|---|
| Move | `W A S D` or Arrow keys |
| Shoot | `SPACE` (hold for auto-fire at Lv 10+) |
| Pause | `P` or `Esc` |
| Mute | `M` or 🔊 button |
| Mobile | 🕹️ Joystick + 🔴 FIRE button |

---

## Features

✨ **Infinite procedural difficulty** — game never stops scaling  
🗺️ **Live Mumbai map background** using Leaflet.js  
⚡ **Powerups** — health, time boost, shield  
🏆 **Global leaderboard** — post scores online  
📱 **Mobile friendly** — touch controls + PWA installable  
🔊 **Web Audio** — procedural sound effects, zero files
